Privacy Policy

Last updated: 28 September 2026

Who uses this app

Pulse Ingest is a private tool operated by its owner for their own use. It is not offered to the public.

What it accesses

The app requests read-only access to the owner's Google Drive, plus basic profile information used only to identify which account is signed in.

What it does with data

The app reads source files for a newsletter and copies their text to the owner's own computer for processing. It cannot create, change, move or delete any file in Drive.

Sharing and storage

No data is sold, shared with third parties, or used for advertising. The OAuth token that authorizes the app is stored only on the owner's own computer.

Revoking access

Access can be revoked at any time from the Google Account's Security settings, under third-party connections.

Contact

Questions can be raised as an issue on this project's GitHub repository.
